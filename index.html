Agentsprinten

Bygg din første AI-agent — på din egen måte

Hva er en agent?

En agent er en AI som ikke bare svarer — den handler. Den søker, husker, beslutter og leverer. Du instruerer den én gang, så kjører den på egenhånd.

Oppdraget ditt

Bygg en agent som henter to ferske nyhetsartikler om et tema du velger og poster dem til deg på Slack — klar når du starter arbeidsdagen. Agenten skal aldri sende samme artikkel to ganger.

To verktøy — to roller
claude.ai (nettleser eller app)

Bruk denne til å tenke, forstå og diskutere. Sitter du fast eller vil du snakke gjennom noe — start her.

Claude Code (Desktop-appen)

Bruk denne til å bygge, kjøre og automatisere. Claude Code lager filer og kjører agenten lokalt på maskinen din.

Før du begynner
Steg 1
Opprett arbeidsmappe og åpne i Claude Code

Lag en ny mappe på maskinen din — f.eks. morgenbriefing. Åpne Claude Code i Desktop-appen og si: «Åpne mappen morgenbriefing som arbeidsområde.» Alt agenten lager havner i denne mappen.

Steg 2
Legg til Slack som connector

I Claude Code Desktop: åpne Customize → Connectors → legg til Slack. Du blir bedt om å logge inn på Slack-arbeidsområdet ditt. Når Slack er koblet til, kan agenten poste meldinger på dine vegne.

Hva agenten består av
SKILL.md
Instruksen din

Beskriver hva agenten skal gjøre, hvilken verdi den skal gi deg, og hvordan meldingen skal se ut. Du skriver denne i oppdrag 01.

agent.py
Selve agenten

Python-scriptet som henter artikler, sjekker hukommelsen og poster til Slack. Claude Code lager dette for deg.

sett_artikler.json
Hukommelsen

Holder styr på hvilke artikler som allerede er sendt. Agenten sjekker denne listen og sender aldri det samme to ganger.

Slack connector
Kanalen

En kobling til Slack-arbeidsområdet ditt, satt opp via Customize i Claude Code Desktop. Agenten bruker denne til å poste morgenmeldingen.

To oppdrag — ingen fasit
01

Legg en plan

Beskriv agenten så tydelig at Claude Code kan bygge den — uten at du skriver en linje kode. Start med verdien du vil ha, ikke teknologien.

Instruksjonsmal — fyll inn det som er markert
Jeg vil lage en morgenagent som:
— Søker etter to ferske nyhetsartikler om [TEMA]
— Poster dem til meg på Slack hver morgen
— Aldri sender det samme to ganger

Verdien for meg er [HVA DU VIL OPPNÅ].
En god melding skal [HVA SOM GJØR DEN NYTTIG FOR DEG].

Lag en plan. Ikke skriv kode ennå.
  1. 1 Fyll inn malen over og lim den inn i Claude Code. Observer hva Claude Code spør om tilbake, og svar så konkret du kan.
  2. 2 Les planen Claude Code foreslår. Juster til du er fornøyd, og si deretter: «Lagre planen som SKILL.md i arbeidsmappen.» Dette dokumentet er utgangspunktet for oppdrag 02.
Usikker på noe? Spør i claude.ai-chatten
02

Bygg og lever

Du har en plan. Nå skal Claude Code bygge agenten basert på den. Følg med på hva som skjer — du trenger ikke forstå koden, men du bør forstå hvert steg.

  1. 1 Si til Claude Code: «Bygg agenten basert på SKILL.md.» Claude Code lager filene som trengs og stiller spørsmål underveis. Svar så godt du kan.
  2. 2 Bekreft at Slack-connectoren er aktiv (satt opp i steg 2 over). Si til Claude Code: «Bruk Slack-connectoren til å sende morgenbriefingen til kanalen #morgenbriefing.» Claude Code bruker tilkoblingen du allerede har satt opp.
  3. 3 Test agenten manuelt. Si: «Kjør agenten én gang nå.» Sjekk Slack-kanalen. Ser meldingen slik du hadde tenkt? Juster og kjør på nytt til du er fornøyd.
  4. 4 Sett opp automatisk kjøring. I Desktop-appen: Code → Routines → New routine → Local. Sett klokkeslett til f.eks. 07:00. Agenten sender automatisk når maskinen våkner — selv om det planlagte tidspunktet er passert.
Noe som ikke virker? Beskriv problemet til Claude Code
Teknisk kit
  • Verktøy Claude Desktop-appen med Claude Code innebygd
  • Språk Python — Claude Code skriver og kjører det, du trenger ikke kunne det
  • Minne Agenten lagrer sette artikler i sett_artikler.json — en lokal fil i mappen din
  • Utsending Slack via connector — kobles til i Claude Code Desktop under Customize → Connectors
  • Kjøring Routines i Claude Code Desktop — sender automatisk når maskinen våkner om morgenen
