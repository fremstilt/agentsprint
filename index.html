Agentsprinten

Bygg din første AI-agent — på din egen måte

Hva er en agent?

En agent er en AI som ikke bare svarer — den handler. Den søker, husker, beslutter og leverer. Du instruerer den én gang, så kjører den på egenhånd.

Oppdraget ditt

Bygg en agent som henter to ferske nyhetsartikler om et tema du velger og sender dem til deg på e-post — klar i innboksen når du starter arbeidsdagen. Agenten skal aldri sende samme artikkel to ganger.

Før du begynner — sett opp arbeidsområdet
Steg 1
Opprett en mappe

Lag en dedikert prosjektmappe på maskinen din — f.eks. morgenbriefing. Alt agenten lager lever her: script, historikk, logg.

Steg 2
Åpne i Claude Code

Start Claude Code i Desktop-appen og åpne mappen som arbeidsområde. Du jobber lokalt — filene dine, på maskinen din.

Steg 3 — nøkkellæring
Instruksen blir en SKILL.md

Planen du lager i oppdrag 01 lagres som SKILL.md i mappen. Det er et dokument Claude Code leser og handler etter — selve designarbeidet ditt.

Tre oppdrag — ingen fasit
01

Legg en plan

Oppdraget du nettopp har lest er utgangspunktet. Ta det med inn i Claude Code — men ikke be om kode ennå. Beskriv agenten som om du onboarder en ny kollega: hvem er den til, hva skal den levere, og hvilken verdi skal den gi deg? Tenk gjennom hvordan den perfekte morgenbriefingen ser ut: hva inneholder den, og hvordan er den skrevet?

Be Claude Code lage en plan basert på beskrivelsen din. Les planen, still spørsmål og juster til du er fornøyd. Gå ikke videre til oppdrag 02 før planen er på plass.

Start med: «Hvilken verdi skal agenten gi meg?»
02

Bygg og lever

Du har en plan. Be Claude Code bygge agenten basert på den. Beskriv resultatet du vil ha — ikke steg for steg. Agenten skal huske artiklene den allerede har sendt og aldri levere det samme to ganger. Kjør den manuelt én gang for å se hva du faktisk får.

Prøv å kjøre agenten manuelt én gang for å se resultatet
Teknisk kit
  • Verktøy Claude desktop-appen med Claude Code innebygd
  • Minne Agenten lagrer sette artikler i sett_artikler.json
  • E-post Gmail via SMTP — krever et App-passord fra Google-kontoen din (ikke vanlig passord)
  • Kjøring Routines-fanen i Claude Code Desktop. Sett til f.eks. 07:00 — sender automatisk når maskinen våkner om morgenen, selv om tidspunktet er passert
  • Språk Python — Claude Code håndterer alt, du trenger ikke kunne det
